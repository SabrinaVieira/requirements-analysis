## Requisitos Funcionais (RF)

- **RF01:** O sistema deve permitir que os participantes visualizem todos os eventos disponíveis em um único lugar.
- **RF02:** O sistema deve enviar um comprovante de inscrição ao participante logo após a efetivação da mesma.
- **RF03:** O sistema deve permitir que os participantes cancelem suas próprias inscrições de forma autônoma, sem intervenção da organização.
- **RF04:** O sistema deve possibilitar a emissão de certificados pelos participantes após a conclusão do evento.
- **RF05:** O sistema deve permitir a inscrição de um participante em múltiplos workshops que ocorram no mesmo dia.
- **RF06:** O sistema deve realizar o controle automático da quantidade de vagas disponíveis em cada evento.
- **RF07:** O sistema deve criar e gerenciar uma lista de espera automaticamente assim que um evento atingir a capacidade máxima.
- **RF08:** O sistema deve exibir para os organizadores a quantidade de inscritos em tempo real.
- **RF09:** O sistema deve permitir que a equipe financeira confirme os pagamentos no sistema para liberar as inscrições pagas.
- **RF10:** O sistema deve permitir que os palestrantes consultem a lista de participantes inscritos em suas respectivas atividades.
